# VKTE — инженерные проекты: Волга ГАЗ-2410 и УАЗ

Документация по дублирующим (резервным) электронным системам для
ГАЗ-2410 (двигатель ЗМЗ-402), интегрируемым в BlueOS, и по проекту
электропривода на базе УАЗа.

## Модули

- [`ignition/`](ignition/ignition_parts.md) — дублирующая система
  зажигания: штатный трамблёр + МПСЗ с силовым переключением между
  контурами.
- [`telemetry/`](telemetry/telemetry_rs485.md) — цифровая шина
  телеметрии на RS-485 (Modbus RTU) для сбора показаний датчиков
  (температура, ток, напряжение) и передачи их в BlueOS.
- [`plc/`](plc/prompt_for_claude.md) — готовый промт для Claude:
  список устройств и техзадание на программу ПЛК (Structured Text,
  OpenPLC), реализующую интерлок зажигания и опрос телеметрии.
- [`powerline/`](powerline/powerline_comm.md) — мост PLC (Power Line
  Communication) Ethernet <-> бортовая сеть 12В, для передачи данных
  без прокладки отдельного кабеля. Не путать с `plc/` (там PLC —
  Programmable Logic Controller).
- [`purchasing/`](purchasing/ozon_shopping_list.md) — консолидированный
  список покупок для Ozon/AliExpress по всем модулям с поисковыми
  запросами и техническими требованиями.
- [`engine/`](engine/engine_transmission.md) — проект УАЗ: выбор
  архитектуры привода (электромотор + КПП vs e-Axle vs синтез с
  раздаточной коробкой) для экспедиционных и водолазных задач.

Модули `ignition/`, `telemetry/`, `plc/`, `powerline/` рассчитаны на
совместную работу на Волге ГАЗ-2410: линия телеметрии (RS-485, витая
пара) прокладывается отдельно от проводки зажигания и МПСЗ, чтобы
избежать взаимных наводок. Модуль `engine/` относится к отдельному
проекту (УАЗ) и пока не связан с остальными.

Каждый модуль состоит из генератора (`generate_*.py`), формирующего
итоговый markdown-документ, и самого сгенерированного файла.
