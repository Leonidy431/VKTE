## ⚙️ **НАСТРОЙКИ PRINT PROFILE (PLA+)**

### **PrusaSlicer 2.7 Optimizer**

```ini
# === СЛАЙСЕР КОНФИГУРАЦИЯ ===
[printer]
nozzle_diameter = 0.4
layer_height = 0.15           # Качество деталей (критично для герметичности)
first_layer_height = 0.20     # Лучший адгезия

[filament]
filament_type = "PLA+"
nozzle_temp = 215             # Prusa рекомендует 215 для PLA+
bed_temp = 60                 # Хорошо прилипает без тепловых деформаций

[print]
# === СКОРОСТЬ ===
perimeter_speed = 45          # Внешние стенки (качество видимо)
infill_speed = 70             # Внутри быстрее
travel_speed = 150            # Перемещение между точками
first_layer_speed = 20        # Первый слой медленно

# === ЗАПОЛНЕНИЕ ===
infill_density = 15           # 15% заполнение (лёгкий, но жёсткий)
infill_pattern = "gyroid"     # Гироидальное заполнение (прочность без веса)

# === ПОДДЕРЖКИ ===
support_material = "TREE"     # Tree supports (меньше отходов, легче снимаются)
support_density = 10          # Редкие поддержки
support_angle = 45            # Угол поддержек

# === АДГЕЗИЯ ===
raft_layers = 1               # Один слой raft (улучшает адгезию, легко снимается)
skirt_height = 1              # Тест линия перед печатью

# === КАЧЕСТВО ПОВЕРХНОСТИ ===
extra_perimeters_on_overhangs = 1   # Дополнительные стенки где overhang
small_perimeter_speed = 25          # Маленькие детали медленнее
```

### **Вывод конфига:**
```bash
PrusaSlicer \
  --load "profile_pla_plus.ini" \
  --load-config "support_tree.ini" \
  --export-gcode enclosure_frame.stl \
  --output "enclosure_frame.gcode"
```

## 📐 **ЭКСПОРТ STL ИЗ OPENSCAD**

Для каждого узла из `ballistic_corrector_asm.scad`:

```bash
#!/bin/bash
# export_stl.sh — автоматический экспорт всех узлов

OPENSCAD="/Applications/OpenSCAD.app/Contents/MacOS/OpenSCAD"  # macOS
# или OPENSCAD="openscad" для Linux

# Функция экспорта модуля
export_module() {
  local module=$1
  local output=$2
  echo "Экспортирую $module -> $output"
  
  $OPENSCAD -D "EXPORT_$module=true" \
    -o "stl/$output.stl" \
    -s 0.1 \
    ballistic_corrector_asm.scad
}

# Экспортируем все узлы
export_module "ENCLOSURE_FRAME" "enclosure_frame"
export_module "CONNECTOR_PANEL" "connector_panel"
export_module "HACKRF_BRACKET" "hackrf_bracket"
export_module "ULTRASONIC_BRACKET" "ultrasonic_bracket"
export_module "MAGNETIC_BASE" "magnetic_base"
export_module "GIMBAL_FRAME" "gimbal_frame"
export_module "GIMBAL_BEARING" "gimbal_rotation_bearing"
export_module "GIMBAL_ANTENNA" "gimbal_antenna_mount"
export_module "CABLE_TRAY" "cable_management_tray"
export_module "SERVICE_DOOR" "service_door"
export_module "M2_STANDOFF" "m2_standoff_with_snapfit"
export_module "QUICK_RELEASE" "quick_release_clip"

echo "✅ Все STL готовы к печати"
```

## 🎯 **РЕЗУЛЬТАТЫ ПЕЧАТИ (ожидаемые)**

### **Качество поверхности (PLA+, слой 0.15mm):**
- Внешние стенки: гладкие, видна текстура слоёв (ожидаемо)
- Внутренние пазы: точность ±0.3mm (нормально для FDM)
- Скругления: гладкие (благодаря Минковскому в SCAD)
- Snap-fit язычки: толщина 2mm, гибкие (проверить вручную)

### **Проверки после печати (для каждого узла):**

| Узел | Проверка | Критерий принятия |
|------|----------|------------------|
| **1** Корпус | Герметичность швов | Нет видимых щелей, стенки не расслоены |
| **2** Коннекторы | Отверстия открыты | SMA Ø5.5mm входит без трения |
| **3a,3b** Кронштейны | Пазы по оси | HackRF/Ultrasonic входят с зазором 0.2mm |
| **4** Магниты | Утопленность | Магниты утоплены на 1mm (не выступают) |
| **5** Гимбал | Концентричность | Внутреннее кольцо соосно оси ±1mm |
| **7** Кабельный лоток | Гермоходы | Отверстия Ø3mm не забиты пластиком |
| **8** Дверь | Шарнир | Ось Ø4mm входит гладко, люфт <0.5mm |

## 🔧 **ПОСТОБРАБОТКА (2 часа на все детали)**

### **После снятия с платформы:**

1. **Удаление поддержек** (30 мин)
   - Tree supports снимаются руками (обычно легко)
   - Если трудно → нагреть с феном (60°C)
   - Небольшие остатки — шлифовка наждаком 240

2. **Шлифовка контактных поверхностей** (30 мин)
   - O-ring пазы: наждак 320 + 600 (гладкая поверхность)
   - Snap-fit язычки: проверить гибкость (не хрупкие)
   - Пазы для модулей: убрать острые края

3. **Мытьё спиртом + сушка** (30 мин)
   - Удалить остатки пластика, пыль
   - Сушка в проветриваемом месте (1-2 часа)

4. **Финишная сборка** (30 мин)
   - Вставить O-ring в пазы (смазка силиконом)
   - Проверить snap-fit язычки (гибкость + фиксация)
   - Собрать прототип без винтов (ручная проверка коллизий)
