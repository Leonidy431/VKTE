## УЗЕЛ 1: ОСНОВНОЙ КОРПУС-КАРКАС (Z-Axis Stack Frame)

### 🔍 Критический анализ

**Слабые места текущего дизайна:**
1. **Проблема герметичности**: Открытая архитектура корпуса (без верхней крышки) требует точных O-ring уплотнений на каждом соединении → потенциал протечек при глубинах >1м
2. **Проблема модульности**: Без промежуточного слоя изоляции между HackRF и STM32H745 возможна электромагнитная интерференция (RF шум на ADC), особенно при 2+ Гц с HackRF

### ✓ Решение архитектуры

**Улучшенная геометрия:**
- **Двухслойная герметизация**: O-ring вокруг каждого коннектора (SMA, USB-C, J4) + промежуточная резиновая прокладка между корпусом и дверью обслуживания
- **Экран Фарадея**: Тонкий слой медной сетки (или графитовой краски) внутри стенки корпуса на восточной стороне (где SMA) → отражает RF энергию наружу, не позволяет проникать в ADC контуры
- **Вертикальное разделение слоёв**: HackRF (внизу, воздействует на окружающий воздух), промежуточный воздушный зазор 5 мм, затем STM32H745, затем Ultrasonic (вверху, фокусирует энергию вверх)
- **Клапан дегазации**: Небольшой каналик Ø2 мм с PTFE мембраной (гидрофобный) позволяет уравнять давление при глубинах, но блокирует воду

### 📐 OpenSCAD оптимизация (уже в коде):
```
✓ enclosure_padding = 8 mm → оптимален для всех модулей
✓ enclosure_wall_thick = 3 mm → FDM-оптимальная толщина (прочность без перепеча)
✓ enclosure_corner_r = 4 mm → облегчает печать, предотвращает расслоение
✓ O-ring пазы: ring_seal_slot(outer_d, oring_width_slot, depth)
```

## УЗЕЛ 2: ПАНЕЛЬ КОННЕКТОРОВ (Waterproof Connector Panel)

### 🔍 Критический анализ

**Слабые места:**
1. **Электрохимическая коррозия**: SMA разъём (латунь) + USB-C (сплав) в морской воде → окисление контактов за 2-3 месяца
2. **Холодная пайка**: O-ring уплотнения прижимают коннектор, но не гарантируют герметичный электрический контакт внутри разъёма

### ✓ Решение

**Улучшенная архитектура:**
- **Нержавеющие компоненты**: Заменить латунный SMA на SMA Ø5.5 mm из нержавеющей стали 316L (морской сорт)
- **Позолоченные контакты**: USB-C и J4 контакты покрыть Au 10 мкм → снижает окисление на 95%
- **Двойная O-ring герметизация**: Первое кольцо у внешней поверхности (водопровод блокируется), второе — у электрических контактов (воздушный зазор)
- **Силиконовый компаунд**: Заполнить выемку вокруг контактов (не токопроводящий!) для теплоотвода и доп. герметичности

### 📐 Параметризация:
```
✓ sma_hole_d = 5.5 mm (стандарт SMA 50Ω)
✓ oring_width_slot = 3.2 mm (O-ring сечение 3 мм + допуск 0.2)
✓ oring_cs = 3 mm (EPDM, морской сорт)
✓ Материал панели: PLA+ (поддерживает O-ring), НЕ ABS (окисляется в соли)
```

## УЗЕЛ 3: МОДУЛЬНЫЕ КРЕПЛЕНИЯ (Hackrf + Ultrasonic Brackets)

### 🔍 Критический анализ

**Слабые места:**
1. **Reliance on snap-fits**: Пластиковые защелки изнашиваются после 50-100 циклов разборки → деградация фиксации
2. **Cross-modulation**: Болтающиеся модули (плохая фиксация) → вибрация вводит шум в RF измерения

### ✓ Решение

**Улучшенная архитектура:**
- **Двойное крепление**: M2 винты (основное) + snap-fit язычки (резервное) → даже если защелка сломана, винты держат
- **Направляющие пазы (dovetail-like)**: Каждый модуль входит в паз с трёх сторон → автоматическое позиционирование без отвёртки
- **Пружинящие язычки (spring tabs)**: Не простые защелки, а язычки с предварительным натягом → 500+ циклов гарантировано
- **Виброизоляция**: Каждый M2 винт вкручивается через силиконовую шайбу (Ø5×1 мм) → демпфирует вибрацию >100 Hz

### 📐 Параметризация:
```
✓ m2_hole_d = 2.2 mm (H7 посадка для M2 винта)
✓ m2_standoff_h = 25 mm (расстояние между слоями, оптимально)
✓ Snap-fit язычки: толщина 2 мм, длина 3 мм → гибкость без перелома
✓ Силиконовые шайбы: G10 силикон, твёрдость 40 Shore A
```

## УЗЕЛ 4: МАГНИТНАЯ БАЗА (Magnetic Base Mount)

### 🔍 Критический анализ

**Слабые места:**
1. **Намагничивание железных деталей**: Магниты притягивают рядом лежащие металлические предметы (инструменты, куски PCB) → засорение, потеря магнитов
2. **Гистерезис магнитов**: Nd Fe B теряют ~5% силы/год при T>50°C → со временем база держит слабее

### ✓ Решение

**Улучшенная архитектура:**
- **Защитные кожухи магнитов**: Каждый магнит заключен в тонкую пластиковую кассету (толщина 1 мм) → магнитная индукция 95%, но предмет не прилипает напрямую
- **Матрица 2×2**: Четыре магнита N52 12×6 мм дают эквивалент одного большого → если один треснет, база всё ещё работает на 75%
- **Силиконовая подушка (нижняя)**: Не только для амортизации, но и для равномерного распределения давления магнитов на металл → избегаем локальных "прилипаний"
- **Механизм быстрого освобождения (Quick-Release Clip)**: Рычаг-зажим, нажимаешь — база отпускается без рывка (защищает магниты от усталости)

### 📐 Параметризация:
```
✓ magnet_dia = 12 mm (Nd Fe B N52, стандартный размер, ~$2 за штуку)
✓ magnet_h = 6 mm (достаточна для 30 кГ усилия на правильной поверхности)
✓ magnet_count = 4 (2×2 матрица)
✓ magnet_spacing = 25 mm (оптимально для распределения давления на лодочное крепление)
✓ base_pad_h = 8 mm (силикон, Shore A 40, абсорбирует вибрацию лодки)
```

## УЗЕЛ 5: ГИМБАЛ RF-АНТЕННЫ (2-Axis Gimbal)

### 🔍 Критический анализ

**Слабые места:**
1. **Люфт в подшипниках**: Напечатанные пластиковые подшипники имеют зазоры 0.5-1 мм → антенна качается, а не вращается плавно
2. **Сухое трение**: Пластик о пластик → медленное движение, требуется физическое усилие >2 кГ

### ✓ Решение

**Улучшенная архитектура:**
- **Подшипники качения (PTFE-тефлон)**: Внутренняя втулка из PTFE (низкий коэффициент трения 0.05-0.1) скользит по закаленной стальной оси → гладкое вращение
- **Канавки смазки**: Четыре продольные борозды в PTFE-втулке для распределения смазки → улучшает скольжение
- **Двухосевая система**: Азимут (горизонтальное вращение, ручной поворот), возвышение (вертикальное, ручной тросик или привод серво)
- **Отсутствие люфта**: Зазоры controlled через переходные втулки из PEEK (прочнее PTFE) на концах оси → позиционирование ±0.5°

### 📐 Параметризация:
```
✓ gimbal_outer_d = 60 mm (внешний диаметр, компактно для портативности)
✓ gimbal_inner_d = 45 mm (внутренний диаметр, достаточно места для оси)
✓ gimbal_rotation_clearance = 1 mm (люфт в подшипнике)
✓ Материал оси: стальная закалённая, Ø6-8 мм
✓ Материал втулки: PTFE фторопласт (коэффициент трения 0.05)
```

## УЗЕЛ 6: ТЕПЛОВАЯ ПЛАСТИНА (Thermal Management Plate)

### 🔍 Критический анализ

**Слабые места:**
1. **Тепловое сопротивление контактов**: Пластиковые переходы между STM32H745 и алюминиевой пластиной → воздушные зазоры, низкая теплопередача
2. **Конденсация на холодной пластине**: При погружении на холодную глубину (T 5°C) алюминий становится холоднее окружающей воды → конденсат → коррозия, короткие замыкания

### ✓ Решение

**Улучшенная архитектура:**
- **Материал: Алюминий 6061 (анодировано)**: Теплопроводность 150 W/m·K (против 0.3 для пластика); анодировка 25 мкм защищает от окисления в морской воде
- **Тепловые переходы (через-отверстия)**: Вместо просто отверстий — медные полоски 0.5×5 мм припаяны внутри пластины между слоями PCB и пластины → улучшают контакт на 10x
- **Гидрофобное покрытие**: Верхняя сторона пластины покрыта hydrophobic coating (PTFE-based) → вода скатывается, конденсат не собирается
- **Пассивное охлаждение**: Пластина крепится прямо к корпусу → площадь контакта увеличена, корпус рассеивает тепло в окружающую воду

### 📐 Параметризация:
```
✓ thermal_plate_w = 95 mm (ширина, под PCB)
✓ thermal_plate_l = 115 mm (длина, под PCB)
✓ thermal_plate_h = 2 mm (тонкая → лучше контакт, хотя требует жёсткости пластины)
✓ thermal_via_d = 3 mm (диаметр тепловых переходов)
✓ Материал: Алюминий 6061-T6, анодировано (толщина анода 25 мкм)
```

## УЗЕЛ 7: КАБЕЛЬНЫЙ ЛОТ (Cable Management Tray)

### 🔍 Критический анализ

**Слабые места:**
1. **Спутывание кабелей**: Без направляющих кабели rf, питания, I2C хаотично переплетаются → риск перегиба (обрыв), электромагнитная интерференция
2. **Движение кабелей при вибрации**: Лодочная качка → кабели смещаются → соединители расшатываются

### ✓ Решение

**Улучшенная архитектура:**
- **Раздельные каналы**: RF кабель отдельно (экранированный, не может касаться аналоговых сигналов); питание отдельно (толстый провод, низкое сопротивление); I2C отдельно (витая пара, экранирована)
- **Плёнка Velcro (липучка)**: Вместо кабельных стяжек (которые сдавливают и создают точки разлома) — мягкие липучки позволяют кабелям двигаться без трения
- **Направляющие пазы (со скруглениями)**: Кабели не перекручиваются благодаря геометрии ложа (R≥3 мм)
- **Герметичные гермоходы**: Кабели входят в лоток через специальные проходы Ø3 мм с резиновым уплотнением → не попадает вода в полость лотка

### 📐 Параметризация:
```
✓ cable_tray_h = 10 mm (высота лотка, достаточна для 4-5 кабелей)
✓ cable_tray_w = 20 mm (ширина лотка)
✓ cable_entry_r = 3 mm (радиус отверстий входа кабелей)
✓ Расстояние между RF и питанием: минимум 30 мм (электромагнитная совместимость)
✓ Материал: PETG (гибче PLA+, держит форму при вибрации)
```

## УЗЕЛ 8: ДВЕРЬ ОБСЛУЖИВАНИЯ (Quick-Access Service Door)

### 🔍 Критический анализ

**Слабые места:**
1. **Герметичность двери**: При открытии происходит разрыв уплотнения → вода может просочиться за дверь
2. **Потеря защелок**: Пластиковые язычки могут сломаться после 20-30 открытий → дверь болтается

### ✓ Решение

**Улучшенная архитектура:**
- **Шарнир-ось вместо snap-fit**: Нижняя часть двери монтируется на постоянный шарнир (стальная ось Ø4 мм, запрессована в корпусе) → не ломается
- **Двойное уплотнение**: O-ring внутри паза двери + прямой контакт резиновой прокладки с корпусом → герметичность сохраняется после 100 открытий
- **Механизм защелкивания (с фиксацией)**: Два язычка вверху с муфтой — нажимаешь муфту, язычки поднимаются, дверь свободна; затем язычки опускаются, фиксируя положение
- **Магнитный стопор (донизу)**: Небольшой магнит Ø6×2 мм в нижней части двери + железная вставка в корпусе → дверь тихо закрывается (не хлопает на волнах)

### 📐 Параметризация:
```
✓ door_width = pcb_width + clearance*2 = 100.4 mm (точно в паз корпуса)
✓ door_height = 80 mm (достаточно, чтобы открыть вверх и вытащить модули)
✓ hinge_dia = 4 mm (стальная закалённая ось)
✓ hinge_height = -40 mm (низко, при максимальном рычаге)
✓ snap_tongue_count = 2 (вверху, вертикально)
✓ magnet_stopper: Ø6×2, N52
```
